
# MD5_user_password_convter:
- during one of the CTF challenges I need to bruteforce a cookie for an admin user
- the format of the cookie was base64 that consists of user:md5_password_hash
- To try thousnads of passwords, I needed to create my own script.

# 🔥 Usage:
- The script takes 3 arguments:
- 1- the password list
- 2- the username
- 3- the ouput file name
